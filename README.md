Project 1:

Extract
Extract financial transactions from the:
-  SQL Server,
-  exchange rates from the API call,
-  exchange rates from the Excel file,
-  and supplier data from the CSV file.

Transform
Perform transformations such as lookups to enrich transaction data with customer and supplier details. 
Convert transaction amounts to a common currency using the exchange rates from the API call and the Excel file.

Load
Store the transformed data  into a data warehouse for for further analysis.
